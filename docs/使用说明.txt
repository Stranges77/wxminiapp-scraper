==================================================
  微信小程序商品采集脚本 使用说明
  脚本: 开始采集.py (一键) + probe_cdp.py (体检) + wx_scraper.py (采集)
  依赖工具: WMPFDebugger (开源, 位于 third_party 目录, 已随本项目附带)
  版本: v1.0.0
  说明: 本文件与仓库根目录 README.md 内容保持同步,
        修改代码/流程时两份文件必须一起改。
==================================================


【脚本简介】
本工具通过 PC 微信的远程调试通道 (CDP), 像操作网页一样
采集微信小程序里展示的商品图片和文本:

  - 商品图片 (主图 / SKU图 / 详情长图 / 尺码表,
    自动过滤图标、头像、横幅等素材图)
  - 商品标题 / 价格 / 销量 / 服务标签
  - SKU 规格 (颜色、尺码等分组选项)
  - 商品详情参数表 (材质、版型、品牌等结构化键值对)

已适配: 微信内 WebView 渲染的商品详情页 (已在快手小店验证)。

原理:
  PC 微信的小程序跑在 WeChatAppEx.exe (Chromium 内核) 里,
  微信内置了远程调试功能但对外做了限制。
  开源工具 WMPFDebugger 用 Frida 解锁这个限制,
  在本机暴露标准 Chrome DevTools Protocol (CDP)。
  我们的脚本用 Python 直连 CDP, 读取已渲染的页面 DOM。

  ⚠️ 本工具仅供个人学习研究, 禁止商业用途和大规模爬取,
     详见仓库根目录 LICENSE。建议使用微信小号。


【目录结构】
  项目根目录/
  ├─ 开始采集.py              一键入口 (日常用这个)
  ├─ wx_scraper.py            采集器核心
  ├─ probe_cdp.py             环境体检
  ├─ requirements.txt         Python 依赖
  ├─ docs/使用说明.txt         本文件
  ├─ third_party/WMPFDebugger/ 注入工具 (Node/TS 项目)
  ├─ tools/                   微信升级后的版本适配工具
  └─ output/                  采集结果输出 (自动创建)


==================================================
前置条件清单 (开始前请确认)
==================================================

  [ ] 电脑装了 Windows 版微信 (4.x 最新版)
      下载: https://pc.weixin.qq.com/
      注意: 必须是 PC 版, 不是网页版

  [ ] 电脑装了 Python 3.10+
      验证: PowerShell 输入 python --version, 显示版本号即可

  [ ] 电脑装了 Node.js LTS v22
      下载: https://nodejs.org/ (选 LTS 版本)
      验证: PowerShell 输入 node --version, 显示 v22.x.x 即可

  [ ] 微信里至少打开过一次小程序 (让运行时下载完成)
      在微信里随便点开一个小程序, 看到内容即可关掉


==================================================
第一步: 装环境 (每台新电脑只做一次)
==================================================

  以下命令均在【项目根目录】执行
  (在资源管理器里进入项目文件夹, 地址栏输入 powershell 回车)。

--- 1A. 安装 Python 依赖 ---

      pip install -r requirements.txt

  *国内网速慢先换清华源 (一次性永久生效):
      pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

  验证:
      python -c "import httpx, websockets; print('依赖OK')"
  打印「依赖OK」即成功


--- 1B. 安装 Node.js + yarn ---

  1. 去 https://nodejs.org/ 下载 LTS v22 版本的 Windows 安装包
  2. 双击安装, 全程下一步即可 (会自动加到 PATH)
  3. 安装完关闭并重新打开 PowerShell, 验证:
         node --version     → 应显示 v22.x.x
         npm --version      → 应显示 10.x.x

  4. 安装 yarn (Node 的包管理器):
         npm install -g yarn
     验证:
         yarn --version


--- 1C. 安装 WMPFDebugger 依赖 ---

  WMPFDebugger 源码已随项目附带 (third_party\WMPFDebugger),
  只需安装它的 Node 依赖:

      cd third_party\WMPFDebugger
      yarn
      cd ..\..

  至此环境全部就绪。


==================================================
第二步: 采集 (二选一)
==================================================

  ★ 方式一: 一键采集 (推荐, 日常用这个) ★

      python 开始采集.py

  脚本自动按 4 步执行:
    [1/4] 检测 PC 微信是否运行
    [2/4] 自动新开窗口启动 WMPFDebugger 注入 (已在运行则复用)
    [3/4] 轮询等待你在微信里打开商品详情页 (最长 5 分钟)
          —— 若 45 秒还没进入调试模式会主动报警提示
    [4/4] 自动调起 wx_scraper.py 开始采集

  你要做的只有:
    ① 登录微信 (建议小号)
    ② 按脚本提示打开小程序、进入商品详情页
    ③ 采集器里按两次回车 (确认页面 → 开始采集)


  ★ 方式二: 手动分步 (首次/排障时用) ★

  这一步的顺序非常重要, 弄反了会连不上!

  1. 先打开微信并登录 (建议用小号)
     确保微信主界面可见, 但不要急着打开小程序

  2. 打开 PowerShell, 进入注入工具目录, 启动调试:

         cd third_party\WMPFDebugger
         npx ts-node src/index.ts --debug-frida --debug-main

     *--debug-frida 会显示注入日志 (scene 码等), 排障必需;
      日常采集可不加, 但建议始终加上
     *如果 PowerShell 提示"禁止运行脚本", 用:
         powershell -ExecutionPolicy Bypass
      再执行上面的 npx 命令 (一键脚本已自动处理此问题)

  3. 等待看到这两行提示 (大约 3~5 秒):

         [frida] script loaded, WMPF version: 25558, pid: xxxx
         [frida] you can now open any miniapps

     *WMPF version 显示 25558 表示版本配置加载成功;
      若报 "version config not found: xxxxx" 说明微信升级了
      WMPF, 需要重新适配 → 见文末「微信升级后」

     【关键】看到这行之后, 才能进行下一步!

  4. 这个 PowerShell 窗口不要关, 让它一直开着

  5. 另开一个 PowerShell 窗口, 回到项目根目录:
         体检 (首次必做):  python probe_cdp.py
         开始采集:        python wx_scraper.py


==================================================
第三步: 打开目标小程序 (在注入启动之后!)
==================================================

  1. 在微信里打开目标小程序 (如快手小店)

     ★★★ 入场方式非常重要, 选错会直接崩小程序! ★★★

     安全入口 (调试工具会自动改写为调试模式):
       [推荐] 微信聊天里点开分享的小程序卡片/链接
              (群聊聊天记录里转发的卡片也可以, 已验证)
       [推荐] 微信顶部搜索框搜索后进入
       [推荐] 聊天下拉的「最近使用 / 常用」进入

     危险入口 (禁止使用):
       [崩溃] 「发现页 → 小程序」入口 (scene 1000,
              上游 issue #83 确认会崩掉小程序进程,
              表现为小程序反复闪退 / connected 后马上
              disconnected)

     判断方法 (需加 --debug-frida): 打开小程序后看日志
       [hook] scene: 1036                    ← 安全场景码
       [hook] hook scene condition -> 1101   ← 出现即成功
       [miniapp] miniapp client connected    ← 且不再断开
     若 scene 后没有 "hook scene condition" 一行, 换上面的
     安全入口重新打开即可

  2. 浏览到你想要采集的商品详情页
     - 先不要急着跑脚本, 等页面完全加载好
     - 确认能看到商品图片、标题、详情等内容

  ★ 顺序回顾 (非常重要):
    先启动注入 → 看到 "frida script loaded" → 再打开小程序
    绝对不能反过来!


==================================================
第四步: 体检与采集
==================================================

--- 体检 (首次必做, 确认环境没问题) ---

  在【项目根目录】执行:

      python probe_cdp.py

  脚本会做 5 项检查, 逐项显示 [通过] 或 [失败]:

    检查 1/5  微信 / WMPF 版本
    检查 2/5  CDP 端口 62000 是否在监听
    检查 3/5  WebSocket + Target 枚举
    检查 4/5  DOM 可用性 (WebView 可采集 vs Skyline 无 DOM)
    检查 5/5  图片 URL 样例

  全部 [通过] → 开始采集; 有 [失败] → 按脚本提示逐条解决

--- 采集 ---

      python wx_scraper.py

  脚本列出所有调试目标并自动推荐:
      ✅ 脚本推荐: [x] 🟩webview (bodyLen=370, score=10370)
         (🟩webview 是商品详情所在的 target 类型, 自动优先)
  直接回车选推荐项即可。

  然后按提示操作:
    - 在微信里确认停在商品详情页 (图片文字都加载完)
    - 回到终端按回车
  脚本会自动: 点「立即购买」弹开规格层 (抓颜色/尺码)
    → 滚动加载全部内容 → 展开折叠区 → 提取 → 下载图片


==================================================
第五步: 找结果
==================================================

  跑完后, 在项目根目录的 output 文件夹下会多出一个
  以【商品标题】命名的文件夹 (重名自动加时间戳):

      output\
      └─ 美式阔腿牛仔裤男士春夏潮流...\
         ├─ 图片_01.jpg             ← 商品图按序编号
         ├─ 图片_02.jpg             (均为 JPG/PNG, 自动去 webp)
         ├─ ...
         └─ 商品信息.txt

  商品信息.txt 内容:
      微信小程序商品信息
      采集页面 / 采集时间
      【商品标题】
      【核心信息】价格 / 销量 / 服务标签
      【规格选项 (SKU)】颜色 3 款 / 尺码 9 款 ...
      【商品详情】主材质 / 版型 / 品牌 ... (结构化键值对)


==================================================
采集另一个商品
==================================================

  方法一 (同一小程序内换商品):
    1. 在微信里切到另一个商品详情页
    2. 回到 PowerShell 按 Ctrl+C 停掉
    3. 重新运行 python wx_scraper.py (或 python 开始采集.py)

  方法二 (换一个小程序):
    1. 在微信里切到另一个小程序的商品详情页
    2. 运行 python wx_scraper.py --list 列出所有页面手动选

  每次采集结果存在 output 下单独的文件夹, 不会覆盖


==================================================
采集完毕后 (收尾)
==================================================

  1. 在注入窗口按 Ctrl+C 停止 WMPFDebugger
  2. 重启微信 (关闭再打开) → 调试注入自动解除, 恢复正常
     (注入只在内存, 不修改微信文件)


==================================================
微信升级后 (调试失效)
==================================================

  现象: 注入时报 "version config not found: xxxxx"
  原因: 微信自动升级了 WMPF 小程序运行时, 地址配置失效

  处理: 用项目 tools 文件夹里的适配工具:
      tools\wmpf_adapt.py   — 自动扫描新版本并生成地址配置
      tools\wmpf_dump.py    — 手动 dump (自动适配失败时用)

  适配工具依赖 (仅适配时需要, 日常采集不用装):
      cd tools
      python -m venv .venv
      .venv\Scripts\pip install -r requirements.txt
      .venv\Scripts\python wmpf_adapt.py

  生成的 addresses.xxxxx.json 放入:
      third_party\WMPFDebugger\frida\config\win32\
  然后重启注入即可。

==================================================
常见问题速查
==================================================

  现象                            | 原因 / 解决
  --------------------------------|------------------------------------------
  node 不是命令                   | 没装 Node.js, 去 nodejs.org 装 LTS 版
  yarn 不是命令                   | 没装 yarn: npm install -g yarn
  npx 报"禁止运行脚本"            | PowerShell 执行策略限制,
                                  | 用 powershell -ExecutionPolicy Bypass
                                  | (一键脚本已自动处理)
  npx ts-node 报错找不到模块      | 没装 WMPFDebugger 依赖:
                                  |   cd third_party\WMPFDebugger; yarn
  看不到 frida script loaded      | 微信没登录 / 版本太旧 / 杀软拦截
                                  | → 确认微信 4.x 登录正常, 杀软加白名单
  frida loaded 但端口连不上       | 打开小程序的顺序反了
                                  | → 必须先看到 loaded 再打开小程序
  probe 体检全失败                | 按脚本打印的提示逐条排查
  probe 通过但采集 0 张图         | 当前页面不是商品详情页
                                  | → 在微信里进到有图片的页面再回车
  采不到颜色/尺码                 | 脚本会自动点「立即购买」弹规格层;
                                  | 仍失败就手动点开规格弹层再回车采集
  提示"无 DOM (Skyline)"          | 该小程序用原生渲染, DOM 路线不适用
  微信提示"操作频繁"              | 采集太快触发风控, 停几小时再继续
  小程序打不开 / 调试入口消失     | 重启微信; 不行就清缓存:
                                  |   删掉 %APPDATA%\Tencent\xwechat\
                                  |   \XPlugin\Plugins\RadiumWMPf\ 下的
                                  |   版本目录, 重开小程序自动重建
  下载图片 403                    | CDN 防盗链, 脚本已带 Referer 兜底
  connected 后马上 disconnected   | 从「发现页」入口打开了小程序
  小程序反复闪退后被关闭          | (scene 1000 已知会崩进程)
                                  | → 换聊天卡片/搜索/最近使用入口重开
  version config not found: xxxxx | 微信自动升级了 WMPF 运行时
                                  | → 用 tools\wmpf_adapt.py 适配


==================================================
安全与风控提示
==================================================

  1. 账号安全: Frida 注入有极低概率触发风控, 建议用微信小号
     注入只在内存, 重启微信完全还原, 不修改微信文件

  2. 采集频率: 每天少量商品 = 正常用户浏览量, 风控风险极低
     脚本已内置每张图 0.4~1.2 秒随机间隔, 不要去掉限速

  3. 风控应对:
     - 小程序提示"操作频繁" → 停几小时, 分时段采集
     - 调试入口消失 → 重启微信 / 清 RadiumWMPF 缓存 / 换小号
     - 账号被限制 → 换小号 + 换网络(手机热点), 等 24 小时

  4. 合规: 仅采集自己有权访问的公开商品信息,
     勿高频/商业爬取。详见仓库 LICENSE。

脚本关系
==================================================

  开始采集.py     → 一键入口 (检测微信 → 注入 → 等页面 → 采集)
  probe_cdp.py    → 体检, 确认环境没问题 (首次/换电脑必跑)
  wx_scraper.py   → 实际采集器 (被一键脚本自动调起, 也可单独跑)
  tools\          → 微信升级后的版本适配工具 (日常不用)
  third_party\    → WMPFDebugger 注入工具 (开源第三方, 已附带)
  output\         → 采集结果
